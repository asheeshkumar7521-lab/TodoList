# 📝 Todo List App

A simple and interactive Todo List App built using **HTML, CSS, and JavaScript** to manage daily tasks easily.

## ✨ Features
- ➕ Add new tasks
- 🗑️ Delete tasks
- 📋 Display all tasks dynamically
- ⌨️ Submit tasks using a form
- 🎨 Clean and simple user interface

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (DOM Manipulation & Event Handling)

## 📂 Project Structure
```text
Todo-List/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Getting Started
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `index.html` in your browser.
